 **Fake Profile Detection System**
This project is a machine learning-powered system that detects fake social media profiles using text-based features (like tweets, hashtags, and profile metrics) and image-based features (like profile photos). It integrates:
-ML models: Random Forest, XGBoost
-Framework: Flask (for backend API)
-Dataset: Twitter Bot Detection Dataset (for text) & Real and Fake Face Dataset (for images)# Fake-Social-Media-Detection
